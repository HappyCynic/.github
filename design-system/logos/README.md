# Logos

The official Happy Cynic marks, exported from the master Illustrator file.

- `happycynic-logo.svg` / `.png` — the full lockup: face plus "Happy Cynic / SOFTWARE". Light grounds only (`surface`, `surface-raised` in light). The wordmark ink is `logo-ink` (#000000); "SOFTWARE" is `teal` (#27a4a3). In the SVG, "SOFTWARE" is live Helvetica text (falling back to Arial): prefer the PNG where Helvetica may be missing. Both SVGs carry their colours as inline `fill` attributes rather than a `<style>` block, so they survive sanitisers and render the same everywhere.
- `happycynic-icon.svg` / `.png` — the face alone: `sunny` (#ffda3c) left, `teal` (#27a4a3) right, `logo-ink` outline on a white disc. Works on light and dark grounds. Use for avatars, app icons, social profiles and the `Endorsement`.
- `favicon-32.png`, `favicon-16.png` — pixel-tuned face for browser tabs. Use only at those exact sizes.

Not yet available: a reversed (white) wordmark for dark grounds, a single-color version for engraving or fax-style use, and a horizontal lockup.
