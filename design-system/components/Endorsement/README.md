# Endorsement

The parent-brand signature for products: the face plus "A Happy Cynic app". This is the one Happy Cynic element every product embeds unchanged.

**Markup:** `<a class="hc-endorse" href="https://happycynic.com"><img src="happycynic-icon.svg" alt="">A <strong>Happy Cynic</strong> app</a>`. Add `hc-endorse--lg` on About screens. The consumer provides the link target and the icon file from the Logos group; the image is decorative (`alt=""`) because the text names the brand.

- Use in a product's About screen, settings footer, website footer and store screenshots. Never on a splash screen or next to the product's own logo at equal size.
- Two wordings only: "A Happy Cynic app" and "Made by Happy Cynic Software".
- Keep it small and quiet in `ink-muted`; it is a signature, not a banner.
- Native apps rebuild it with the same parts: the face at 24pt (40pt large), 8pt gap, 13pt semibold uppercase tracked text.
