# Link

An inline text link in `teal-ink`, underlined so it never depends on color alone.

**Markup:** `<a class="hc-link" href="…">`. The consumer provides descriptive link text: the words should make sense out of context ("source on GitHub", never "here").

- Use inside running text. For standalone actions use a `Button`; for site navigation use the `SiteHeader` nav.
- Hover thickens the underline rather than changing color.
