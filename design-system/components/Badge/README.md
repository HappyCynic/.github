# Badge

A small uppercase status label for products and features.

**Markup:** `<span class="hc-badge hc-badge--sunny">Coming Soon</span>`. Variants: default (neutral), `--sunny` (new, upcoming), `--teal` (available, done), `--danger` (discontinued, error).

- One or two words. The word carries the meaning; color only reinforces it.
- Badges are labels, not buttons: never make them clickable.
