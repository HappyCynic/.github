# SiteFooter

The dark closing band on every Happy Cynic page: the legal line and a one-line tagline on `surface-inverse`.

**Markup:** `<footer class="hc-footer">` with `.hc-footer__legal` and `.hc-footer__tagline`. The consumer provides the current year.

- The legal line reads exactly "© <year> Happy Cynic Software LLC".
- The tagline is one dry sentence in `on-inverse-muted`. Rotate it if you like; keep it under 70 characters.
- Product sites put the `Endorsement` here instead of this tagline.
